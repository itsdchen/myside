ENABLE COREDUMPS
(this is kind of tricky. )
sudo emacs /etc/security/limits.conf
Add these two lines:

* soft core unlimited
* hard core unlimited

Test (after restarting session):
ulimit -c

> Check that this file has this line:
cat /etc/pam.d/cron

# Sets up user limits, please define limits for cron tasks
# through /etc/security/limits.conf
session    required   pam_limits.so

> restart cron so it picks this up.
sudo systemctl restart cron

> Disable apport and prevent it from reenabling itself
sudo sed -i "s/enabled=1/enabled=0/" /etc/default/apport
sudo systemctl stop apport
sudo systemctl disable apport

> Set up our own core pattern to manage raw coredumps
sudo tee /etc/sysctl.d/60-coredump.conf >/dev/null <<'EOF'
kernel.core_pattern=/var/lib/core/core.%e.%p.%h.%t
kernel.core_uses_pid=1
EOF

c /etc/sysctl.d/60-coredump.conf

sudo sysctl --system

should check if this says apport anymore:
> cat /proc/sys/kernel/core_pattern
/var/lib/core/core.%e.%p.%h.%t

make sure that core dir exists. if not, create it and set permissions.
> sudo mkdir /var/lib/core
> sudo chmod 777 /var/lib/core

test it.
> sleep 10 &
> kill -SIGSEGV $!
> ll /var/lib/core/core.sleep.*
should see your sleep core there.
