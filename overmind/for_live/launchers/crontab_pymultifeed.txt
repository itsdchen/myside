# Crontab entry to run pymultifeed at 18:00 Eastern Time daily

# Running it directly with the venv's python because each ; separated command starts up its own shell, which means the activate won't actually activate.

# If your server is in Eastern Time (EST/EDT):
0 18 * * * cd /home/ubuntu/estrader/ && /home/ubuntu/.venvs/v1/bin/python feed/pymultifeed.py --conf feed/feed.json  2>> /home/ubuntu/estrader/logs/feed_logs_$(date +\%Y\%m\%d).log

# To install: run 'crontab -e' and add the appropriate line above
# To check timezone: run 'timedatectl' or 'date'
